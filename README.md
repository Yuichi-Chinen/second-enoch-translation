# 第二エノク書 翻訳プロジェクト

旧約外典「第二エノク書」（教会スラヴ語エノク書、エノクの秘密の書）の日本語訳プロジェクト。[エノク書調査プロジェクト](../エノク書/README.md)の関連プロジェクトとして、第一エノク書の完訳（2026-09-07）を受けて発足。

**進捗: 本文全68章＋付録5章（メルキゼデクの奇跡的誕生、およびノアの箱舟の補記）翻訳完了（2026-09-08）**

## 構成

- [`第二エノク書_調査メモ.md`](./第二エノク書_調査メモ.md) — 成立・伝承・写本状況・権利状況の調査記録
- `原文/` — 収集した英訳・原語資料（[エノク書プロジェクト](../エノク書/)の`原文/`から複製）
- `翻訳/翻訳進行設計書.md` — 底本・体裁・方法論・進捗管理表
- `翻訳/用語対照表.md` — 固有名詞・専門用語の統一表
- `翻訳/第二エノク書/第NN章.md` — 本文（第01〜68章）の章ごとの対訳
- `翻訳/第二エノク書/付録第NN章.md` — 付録（第01〜05章）の章ごとの対訳。写本Sokolovにのみ見られる、本文とは別立ての挿話（メルキゼデクの奇跡的誕生、ノアの箱舟の補記）。詳細は[翻訳進行設計書](./翻訳/翻訳進行設計書.md)§7参照
- `翻訳/読書版/` — 日本語訳のみを組んだ読書版PDF（A5縦書き・全96ページ）と生成スクリプト。訳文を直したら `make_pdf.ps1` で再生成する

## 権利上の方針

`2enoch_slavonic_bldr_navtanovich.*` は著作権表示のあるサイトの収録テキストであるため、本プロジェクトでは**全節の逐語対照（フル・パラレル）は行わない**。翻訳の主たる底本はパブリックドメインのMorfill/Charles英訳（1896）とし、スラヴ語原文は各章末の訳注、または固有名詞・鍵語の確認のための短い引用にとどめる。詳細な運用方針は[翻訳進行設計書](./翻訳/翻訳進行設計書.md)§4を参照。
