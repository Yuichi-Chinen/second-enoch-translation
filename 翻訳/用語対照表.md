# 第二エノク書 日本語訳 — 用語対照表

翻訳全体を通じた訳語の一貫性を保つための対照表。新しい用語が登場するたびに本表を更新する。運用方法は[翻訳進行設計書](./翻訳進行設計書.md)§8を参照。

第一エノク書と共通する固有名詞（エノク等）についても、本表で改めて訳語を定める（プロジェクトが独立しているため）。

| 原語（英訳） | 日本語訳 | 初出章 | 備考 |
|---|---|---|---|
| Enoch | エノク | 第1章 | 語り手・主人公 |
| Methusal | メトシェラ | 第1章 | エノクの長子。スラヴ語原文の綴り「Мефусал」はヘブライ語形に近く、聖書スラヴ語訳の伝統的綴り「Мафусал」とは異なる |
| Regim | レギム | 第1章 | エノクの子 |
| Gaidal | ガイダル | 第1章 | エノクの子。写本Aにのみ記載 |
| Satanail | サタナイル | 第7章 | 第二の天に閉じ込められた堕天使たちの首領。第18章3節で名指される（本章では「その首領」とのみ言及） |
| Grigori / Grigory | グリゴリ（見張りの者たち） | 第18章 | 第五の天に留め置かれた天使の一群。ギリシア語「エグレゴロイ」に由来 |
| Ermon / Mount Iermon | エルモン山 | 第18章 | グリゴリのうち三人が地上に降り立った場所。ヘルモン山 |
| Gabriel | ガブリエル | 第21章 | 大天使。エノクを主の御前に導く |
| Michael | ミカエル | 第22章 | 大天使。「長たる隊長」。エノクに油を注ぎ、栄光の衣を着せる |
| Vretil | ヴレティル | 第22章 | 大天使。天の書記。異本ではプラヴィル、ヴレヴォイル |
| Aravoth | アラヴォト | 第22章 | 第十の天の名（ヘブライ語「アラボット」＝大空に由来） |
| Adoil | アドイル | 第25章 | 深みから呼び出された、光・天の創造の源となる存在 |
| Arkhas | アルカス | 第26章 | 深みから呼び出された、地の創造の源となる存在 |
| Adam | アダム | 第30章 | 七つの実質から創造された最初の人 |
| Eve | エバ | 第30章 | アダムの妻。「母」の意 |
| Satan / Satanail | サタン | 第31章 | サタナイルが天を追われた後の呼び名 |
| Samuil | サムイル | 第33章 | エノクを天から地上へ連れ帰る天使の一人 |
| Raguil | ラグイル | 第33章 | 同上 |
| Ariukh | アリウク | 第33章 | エノクの書物の地上での守護を託される天使 |
| Pariukh | パリウク | 第33章 | 同上 |
| Riman | リマン | 第57章 | エノクの子。第1章には言及なし |
| Ukhan | ウカン | 第57章 | エノクの子。第1章には言及なし |
| Khermion | ケルミオン | 第57章 | エノクの子。第1章には言及なし |
| Achuzan | アフザン | 第64章 | エノクが最後に子らと民を集めた場所。付録第1〜3章にも登場（付録第2章では「アルザン」の異表記あり） |
| Sarsan | サルサン | 付録第1章 | 民の長老の一人 |
| Kharmis | カルミス | 付録第1章 | 民の長老の一人 |

| Sopanima | ソポニマ | 付録第3章 | ニルの妻。老年にして身ごもり、出産の床で死ぬ |
